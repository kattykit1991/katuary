## ✨ About

**KATUARY** is my personal desktop application for macOS and part of my **KATCODED** development universe.

The idea is to create a cozy, customizable digital workspace where I can organize my everyday life, creative ideas, projects and development tools in one place.

KATUARY is designed to grow into a personal organization and command center, with features such as:

- A customizable dashboard with widgets.
- Personal spaces for different interests and projects.
- Notes, tasks and a quick capture area for spontaneous ideas.
- Project management and roadmaps.
- Integration with existing local development tools.
- A private management interface for selected content published on [katcoded.de](https://katcoded.de).

These are long-term product goals, not a list of already completed features.

KATUARY is also a personal learning project. I'm developing it primarily myself to strengthen my software engineering skills through practical experience.

## 🚀 Run locally

### Prerequisites

- Node.js and npm
- Rust and Cargo
- macOS development tools (Xcode Command Line Tools)

### Start the application

Open a terminal in the KATUARY project directory.

Install dependencies:

```bash
npm install
```

Start the desktop application in development mode:

```bash
npm run tauri dev
```

Tauri launches the development server and opens the native application window.
